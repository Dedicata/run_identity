This module creates and keeps a default Keycloak OpenID Connect provider
configured from environment variables.

It is designed for automated deployments where each Odoo database is provisioned
with a Keycloak realm managed outside Odoo.

Configuration
=============

Set the following environment variables in the Odoo container:

* ``DEDICATA_KEYCLOAK_ISSUER_URL``
* ``DEDICATA_KEYCLOAK_CLIENT_ID``
* ``DEDICATA_KEYCLOAK_CLIENT_SECRET``

Optional variables:

* ``DEDICATA_KEYCLOAK_ENABLED``
* ``DEDICATA_KEYCLOAK_PROVIDER_NAME``
* ``DEDICATA_KEYCLOAK_LOGIN_LABEL``
* ``DEDICATA_KEYCLOAK_SCOPE``
* ``DEDICATA_KEYCLOAK_TOKEN_MAP``

Usage
=====

When the required environment variables are present, the module enables the
Keycloak provider automatically. If the issuer URL or client ID is missing, the
provider is kept disabled.
